## CTAs — 8 colocações
Hero · Solução · Para Quem → Depoimentos · Tiers Geral · Tiers VIP · Urgência/Final · Suporte (secundário)

## Identidade visual
- Fundo: preto (#0A0A0A ou similar)
- Destaque: dourado (#C9A84C ou similar)
- Tipografia: sans-serif moderna — hierarquia clara (headline muito grande, sub-headline médio, corpo pequeno)
- Botões CTA principal: fundo dourado, texto preto
- Botão CTA secundário ("Fala Connosco"): outline dourado, sem fundo

## Slippery Slide — regras críticas
- Zero links de navegação — único elemento clicável é o CTA
- Sem menu (apenas logo + botão no header se necessário)
- Sem links externos na página

## Mobile
- Parágrafos máx. 3 linhas
- Botões largura 100% do viewport
- Value stack: cards empilhados (não tabela)
- Grid de mentores: carrossel horizontal
- FAQ: accordion vertical (um de cada vez)
- Tiers: VIP no topo, Geral abaixo
